# Getting help

- **How do I…?** Start with the [README](README.md) and the [docs](docs/). For anything else, open a
  [discussion](https://github.com/r4reetik/keelson/discussions).
- **Something's broken.** [Open a bug report](https://github.com/r4reetik/keelson/issues/new?template=bug_report.yml)
  with your version (`keelson --version`), how you run it, and what you saw.
- **A finding is wrong.** [Report a false positive](https://github.com/r4reetik/keelson/issues/new?template=false_positive.yml).
  Include the check ID and the evidence shown on the finding, with account IDs, hostnames and emails redacted.
- **A check is missing.** [Suggest a check](https://github.com/r4reetik/keelson/issues/new?template=check_request.yml).
- **A security problem in Keelson itself.** Don't open an issue; follow [SECURITY.md](SECURITY.md).

Keelson is not affiliated with Cloudflare, Vercel or AWS. For problems with an account on one of them, contact that provider's support.
