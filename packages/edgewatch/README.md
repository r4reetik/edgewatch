# edgewatch

Edgewatch is now **Keelson**. This package only starts it, so commands and installations from before the rename keep working.

Use the new name from now on:

```bash
npx keelson@latest
```

Your data, credentials and `EDGEWATCH_*` settings are picked up as they are. See [Keelson](https://github.com/r4reetik/keelson#readme) and [upgrading from Edgewatch](https://github.com/r4reetik/keelson/blob/main/docs/upgrading.md#upgrading-from-edgewatch).
